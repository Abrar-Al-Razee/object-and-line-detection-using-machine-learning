**Object-and-line-detection-using-machine-learning** is a versatile developer toolkit for real-time computer vision applications, focusing on object detection, tracking, and spatial analysis. It combines color-based segmentation, event counting, and distance estimation to support robotics, automation, and monitoring systems.

### Why object-and-line-detection-using-machine-learning?

This project empowers developers to implement robust vision-based solutions with ease. The core features include:

- 🟢 **Real-time Object Detection**: Detects and tracks objects based on color, providing live feedback and spatial localization.  
- 🔵 **Dynamic HSV Tuning**: Offers an intuitive GUI for adjusting color thresholds, optimizing detection accuracy.  
- 🟠 **Event Counting & Line Crossing**: Counts objects crossing predefined lines, with serial communication for external responses.  
- 🟣 **Distance & Spatial Estimation**: Calculates object distances and outputs structured data for integration with robotic or monitoring systems.  
- 🟢 **Live Video Streaming**: Facilitates real-time camera feed visualization and control, supporting development and testing.  
- ⚙️ **Modular Architecture**: Comprises multiple scripts tailored for detection, tracking, and hardware interfacing, enabling flexible deployment.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** Python  
- **Package Manager:** Conda  

---

### Installation

Build object-and-line-detection-using-machine-learning from the source and install dependencies:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Abrar-Al-Razee/object-and-line-detection-using-machine-learning.git
``

2. **Navigate to the project directory:**

   ```bash
   cd object-and-line-detection-using-machine-learning
   ```

3. **Install the dependencies:**

   Using **conda**:

   ```bash
   conda env create -f conda.yml
   ```

---

### Usage

Run the project with:

Using **conda**:

```bash
conda activate {venv}
python {entrypoint}
```
